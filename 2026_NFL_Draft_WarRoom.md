## 2. How THIS Scoring Breaks Public Rankings

Yahoo's board assumes ~4-pt passing TDs, no first downs, no completion points, and no IDP. Our league is a different sport.

### Quarterback — the highest-scoring position in this league

| Category | This league | Typical Yahoo | Edge |
|---|---|---|---|
| Completion | **0.5** | 0 | Volume passers print a floor |
| Pass yards | **1 / 20 yds** | 1 / 25 | +25% yardage scoring |
| Pass TD | **7** | 4 | A 3-TD game is +9 vs standard |
| INT | **-1** | -2 | Gunslingers are not punished |
| Pass 1st down | **1** | 0 | 18 first downs = 18 fantasy points by themselves |
| Rush attempt | **0.5** | 0 | Dual-threats stack a second stat line |
| Rush TD | **7** | 6 | Allen/Lamar/Hurts/Daniels cheat code |
| 200/250/300 bonuses | **+4 / +3 / +4** | 0 | A 300-yard game is +11 before TDs |
| 40+ yard play/TD | **+1 / +1** | 0 | Deep-ball QBs get extra |

> [!warning] Do not "wait on QB" like a standard 1QB article tells you.
> Josh Allen can put up 55–80 in a normal week here. The gap from QB1 to QB12 is a playoff seed. We want an elite QB at pick 23 or 26. If both Allen and Lamar are gone, we still take Maye / Burrow / Daniels / Hurts in the next window. We do **not** leave the top 6 QBs for round 10.

### Skill players — PPR + first downs + bonuses

| Category | This league | Why it matters |
|---|---|---|
| Reception | **1.0 PPR** | Slot volume is real money |
| Rec 1st down | **1.0** | Chain-movers (St. Brown, Lamb, Nacua, McBride) jump |
| Rush 1st down | **0.5** | Workhorse RBs still get paid, just less than WR 1sts |
| Rush attempt | **0.5** | 20 carries = 10 pts before yards. True workhorses stay elite. |
| Rush TD / Rec TD | **7 / 6** | Goal-line RBs still punch |
| Rec bonuses | **+3 at 75, +3 at 95, +4 at 115** | 115-yard games explode |
| Rush bonuses | **+3 at 60, +3 at 80, +4 at 100** | 100-yard RBs explode |
| 40+ yard rec/run | **+1**, plus **+1** if it's a TD | Speed merchants (Chase, Achane, JSN, Jameson) get a kicker |

### IDP — this is not a late-round dart

| Category | This league | Translation |
|---|---|---|
| Solo tackle | **3.0** | An 8-solo game is 24 points. That's a WR2. |
| Assist | **1.75** | Combined-tackle machines win |
| TFL | **4.0** | |
| Sack / INT | **7.0 / 7.0** | Splash plays are nice. Tackles are the floor. |
| Pass defended | **4.5** | Ballhawks have a ceiling. Do not start there. |
| Forced fumble | **4.5** | |

> [!tip] IDP law
> Start **two inside linebackers** who play every snap. Pass rushers (Garrett, Hutchinson, Crosby) are boom/bust in this tackle scoring. Safeties are the backup plan. Corners are almost never the pick.

### Kicker — juiced, still not early

PAT is **2 points** (and **-2** if missed). Field-goal yards score at **1 per 10**, on top of distance brackets. Brandon Aubrey is the only kicker worth reaching for, and even he waits until the double-digit rounds. Everyone else is round 13+.

### Team DEF

Sacks 2, INT/FR 3, TD 7, shutout 15. Still streamable. **Do not touch DEF before round 14.**

## 3. Redemption Roster Construction

Last year: bottom two. This year we stop drafting like a 2-RB standard league.

### The build (strict)

```
R1     Elite WR or three-down RB (Gibbs / Chase / Bijan only)
R2–R3  Elite QB + remaining WR1 or workhorse RB
R4–R5  WR volume + RB2/FLEX  (TE only if Bowers/McBride fell)
R6–R8  IDP1 (green-dot LB) + WR/RB depth
R9–R11 IDP2 + TE (if not drafted) + QB2 or upside WR
R12–R13 Best skill leftover / Aubrey if he is the last elite K
R14–R17 K (if needed), DEF, IDP3, handcuff, boom WR
```

**Target finished roster**

| Slot | Count | Profile |
|---|---:|---|
| QB | 2 | One elite, one rushing/volume backup |
| RB | 3 | One workhorse locked into RB, two FLEX/handcuff |
| WR | 5 | Volume first, then a 40-yard burner |
| TE | 1–2 | Bowers/McBride if value; otherwise one mid-tier |
| IDP | 3 | Two every-down LBs + one tackle safety or LB3 |
| K | 1 | Aubrey if possible, else high-volume offense |
| DEF | 1 | Last two rounds |

### Hard rules

1. **Never** draft K or DEF before round 14. Exception: Aubrey in round 12–13 if the skill board is dead.
2. **Never** draft a second QB before you have 1 RB, 3 WR, and 1 elite QB.
3. **Never** start an IDP who is not a linebacker unless both IDP slots are already LB and you are drafting a bench safety.
4. **Never** take James Cook, Josh Allen, or any Bill just to "get a Bill." Allen at 23 is a football pick. Cook at 2 is a fandom pick. We do not fandom-pick.
5. **Never** Zero-RB. You still need one workhorse because rush attempts pay 0.5 each. Get that RB by pick 26 if you took Chase at 2; get a WR1 at 23 if you took Gibbs/Bijan at 2.
6. Low-floor fades (CMC if the board is healthy, Nabers coming off ACL, Kenneth Walker in KC) are only acceptable if they are clearly the last premium name. Prefer high-floor volume.

### Slot-2 philosophy in one sentence

Secure a weekly cheat-code at pick 2, steal the highest-scoring position in the league (QB) at 23/26, then drown the FLEX spots in target volume and two tackle-machine LBs while the rest of the room is still drafting kickers.
